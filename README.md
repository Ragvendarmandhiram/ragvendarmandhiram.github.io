# Ragvendar Mandhiram — Portfolio

AI concept design, spatial concepts, and executed installations.

Website: https://ragvendarmandhiram.github.io/

## Hosting

This is a static HTML, CSS, and JavaScript website. GitHub Pages publishes the `main` branch from the repository root. The `.nojekyll` file keeps the assets unchanged.

## Preview locally

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.

## Update

Edit the HTML, CSS, JavaScript, or image files and push to `main`. GitHub Pages publishes the new version automatically.

## Content

Concept visualizations and executed installations are labeled separately. The About section uses an illustrated creative workspace; the original portrait remains in the header and hero.
